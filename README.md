# Jiale531 的个人作品集

在线访问：https://Jiale531.github.io/

这是一个无需安装依赖的单页 HTML 作品集，支持手机和电脑浏览。

## 更新内容

编辑 `index.html` 中的个人介绍、精选作品和关于我文字，然后提交到 `main` 分支。GitHub Pages 将自动更新网站。

添加真实作品时，可在作品卡片中加入图片、说明和链接。当前两张作品卡片为占位内容。

## 本地预览

直接使用浏览器打开 `index.html`。

## 发布设置

仓库 Settings → Pages → Deploy from a branch → main → / (root)。
